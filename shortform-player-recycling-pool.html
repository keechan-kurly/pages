ExoPlayer 재활용 풀 = 슬라이딩 윈도우

ExoPlayer 생성은 >200ms + 디코더 init ~80ms. 페이지마다 생성/release 하면 스와이프 때 jank. 그래서 창 밖 인스턴스는 release 하지 않고 idle 로 두었다가 새 페이지에 재할당한다.
인스턴스 풀 — 3개 고정
영상이 10개든 100개든 이 3개가 전부. 스와이프해도 개수는 그대로 — 생성 ≤ 3회 · release 없음.
